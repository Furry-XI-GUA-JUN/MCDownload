# MC 临时下载解决方案 (MC Download)

## 📖 项目简介

本项目是一个基于 PowerShell 的临时解决方案。

近期，由于部分原因，PCL (Plain Craft Launcher) 和 HMCL 等主流第三方 Minecraft 启动器暂时无法提供游戏本体及相关依赖的下载服务。为了让大家仍能顺利体验 Minecraft，我编写了这个 `mc.ps1` 脚本。

它可以作为临时替代方案，帮你快速下载游戏核心文件、模组加载器以及 Java 运行环境。

## ✨ 核心特性

- **全版本支持**：可以选择任意已发布（正式版/快照版）的 Minecraft 游戏版本。
- **多加载器支持**：支持选择安装 **NeoForge**、**Forge** 或 **Fabric** 模组加载器。
- **纯净原版**：也支持不安装任何模组加载器，仅下载纯净原版游戏。
- **环境自动配置**：本地若未检测到 Java 环境，脚本会自动为你下载并安装适配的 Java。

## 🚀 如何使用

1. 确保你使用的是 Windows 系统，并已开启 PowerShell。
2. 下载本仓库中的 `mc.ps1` 文件到你的电脑上。
3. 右键点击 `mc.ps1` 文件，选择 **“使用 PowerShell 运行”**。
   *(如果提示权限不足，请右键选择“属性”，勾选“解除锁定”，或在 PowerShell 中执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` )*
4. 根据屏幕提示，输入你想要下载的版本号，并选择对应的模组加载器即可。

## ⚠️ 注意事项

- **安全提示**：本脚本代码完全开源，你可以使用记事本打开查看。请尽量从本 GitHub 仓库下载，防止他人恶意篡改。
- **依赖网络**：脚本的下载速度取决于你与对应下载源（如 Mojang 官方、各类镜像站）的网络连接情况。
